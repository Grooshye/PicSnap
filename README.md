# PicSnap 快捷拼图

把多张照片拼成一张图，发朋友圈再也不用一张张发。橙白配色、中文界面、双击即用。

## 功能特性

- **拖图即拼**：拖拽 / 复制粘贴 / 批量导入照片到图库
- **多组并行**：同时处理多个分组，每组独立拼一张成品图
- **模板 + 框线**：内置 1~9 宫格模板，拖动框线自由改比例
- **自由放格**：图片可放到任意格子，中间可留空
- **格内精调**：右键图片进入编辑 → 滚轮 / `+` `-` 缩放、拖动平移、方向键微调
- **自由模式**：拖动画布外框（四角「＋」、四边「—」）随意改尺寸
- **无框线**：一键无缝拼贴，不留白边
- **允许重复**：同一张图可放进多个分组
- **一键导出**：预设朋友圈尺寸（1080×1080 / 3:4 / 4:3 / 自定义）+ 原图质量，PNG/JPG，复制到剪贴板

## 使用说明

1. 下载 `PicSnap.exe` 后**双击运行**（绿色单文件，放哪都能用）。
2. 点「导入图片」或直接把照片拖进左侧「图片库」。
3. 把图片拖进下方的「分组」或中间的画布格子。
4. 顶部选「张数 / 模板 / 尺寸」，点「导出 / 复制」。

> **首次打开提示**：个人开发者软件未做数字签名，Windows 可能弹出「Windows 已保护你的电脑」蓝色提示，点 **更多信息 → 仍要运行** 即可；个别杀软误报请选「信任 / 允许」。

## 从源码运行 / 打包

```bash
# 运行
python main.py

# 打包成单文件 exe（生成 dist/PicSnap.exe）
python build.py

# 网页版本地预览（浏览器打开 http://localhost:8000）
python -m http.server 8000 --directory web
```

## 技术栈

Python 3.12 · PySide6 (Qt6) · Pillow · PyInstaller

## 目录结构

```
main.py                 # 桌面版程序入口
app/
  main_window.py        # 主窗口
  theme.py              # 橙白主题样式
  models.py             # 数据模型（分组 / 格子）
  core/                 # 导入、模板、渲染引擎、拖拽、设置
  ui/                   # 图库 / 分组 / 画布 / 导出对话框

web/                    # 网页版（手机 / 平板 / 电脑通用）
  index.html
  js/                   # 模型、渲染、画布、图库、分组、导出、模糊
  css/app.css           # 橙白主题 + 响应式布局
tests/selftest.html     # 网页版核心算法自测（18 项）

docs/                   # 需求、技术方案、设计规范等
dev-log/                # 开发日志
```

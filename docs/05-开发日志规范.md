# 开发日志规范

## 位置与命名
- 目录：`dev-log/`
- 文件名：`YYYY-MM-DD.md`（如 `2026-10-27.md`）

## 固定小节
每篇日志包含：
- **今日完成**：当天做完的事（已完成，用「完成」）
- **待办事项**：尚未完成的任务清单（`- [ ]` 勾选格式）
- **下一步**：接下来要做的事
- **遇到的问题**：遇到的坑、待解决事项（没有则写「暂无」）

## 记录流程（自动）
- **会话开始**：先读取 `dev-log/` 里最近一篇日志与待办
- **会话结束**：更新当天日志（没有则新建）
- 只在有开发活动的日子新建日志；无活动不新建

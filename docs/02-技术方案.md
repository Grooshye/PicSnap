# 技术方案

## 技术选型
- **Python 3.12 + PySide6（Qt6）**：桌面 UI；`QGraphicsView/QGraphicsScene` 做可拖动的拼图画布
- **Pillow**：图像处理与导出（LANCZOS 缩放、高斯模糊、马赛克、裁切、合成）
- **PyInstaller**：打包单文件 exe

## 目录结构
```
main.py                  程序入口
build.py                 打包脚本
app/
  main_window.py         主窗口与整体布局
  theme.py               橙白配色 / QSS（样式唯一来源）
  models.py              数据模型：Group、Cell、ImageItem、Template
  core/
    importer.py          导入（拖拽 / 粘贴 / 批量）
    templates.py         内置模板定义（归一化矩形）
    renderer.py          Pillow 合成与导出引擎
    effects.py           模糊 / 马赛克 / 羽化
    exporter.py          保存 PNG/JPG、复制剪贴板
  ui/
    library_panel.py     缩略图库
    groups_panel.py      分组列表
    canvas.py            拼图画布
    grid_item.py         宫格单元
    free_item.py         自由摆放图片项
    props_panel.py       属性面板
    toolbar.py           顶部工具条
docs/                    标准文件
dev-log/                 每日开发日志
```

## 模块职责
- `theme.py`：橙白配色常量与 QSS，全局样式唯一来源
- `models.py`：数据模型（分组、格、图片项、模板）
- `importer.py`：文件导入入口，产出统一图片数据
- `templates.py`：内置模板用归一化矩形 (x, y, w, h) 表示
- `renderer.py`：把画布状态合成为最终图片
- `effects.py`：高斯模糊、马赛克、羽化边缘
- `exporter.py`：写文件与剪贴板

## 核心设计

### 画布
- `QGraphicsView/QGraphicsScene` 承载两种模式：
  - 宫格模式：网格单元（`grid_item`），拖动框线改分栏比例，格间换位
  - 自由模式：图片项（`free_item`）自由摆放、重叠、层级

### 渲染引擎
- 每个格：加载原图 → 按格比例裁切 → 缩放到目标像素 → 粘贴
- 缝隙柔和过渡：相邻接缝处 alpha 渐变羽化

### 模板
- 归一化矩形 (x, y, w, h)，0~1 坐标，JSON 序列化，支持导入导出

# 需求说明

## 概述
Windows 桌面拼图软件「PicSnap 快捷拼图」，把多张照片拼成单图，方便发朋友圈。UI 简洁直观、橙白配色、中文界面。

## 功能需求

### 图片导入
- 拖拽文件进窗口、`Ctrl+V` 粘贴剪贴板图片、批量选择文件
- 一次可导入几十张，进入左侧缩略图库，可增删、排序

### 分组拼图
- 同时处理 ≥9 组，每组拼成 1 张成品图
- 每组 1~9 张（下限 1 张），张数自由增删
- 分组条可停靠到任意一边（上/下/左/右），图片多时分组框可拖动调整大小
- 支持跨组拖动：图片可在分组之间拖动；模板显示时可从某组某格拖到另一组某格

### 模板
- 内置 1~9 格模板（横排/竖排/方阵/不规则；1 格即单图，可加边框/背景）
- 拖动宫格框线自定义布局
- DIY 模板：把当前布局保存为自定义模板；导出/导入模板文件（JSON）

### 宫格模式
- 拖动图片在格间交换位置
- 格内图片缩放 / 平移 / 裁切

### 自由模式
- 图片自由拖动、缩放、重叠、调整层级（置顶/置底）

### 缩放交互
- 支持 Ctrl+滚轮 / 触控板：缩放画布视图、调整图片大小（阶段 3/4 实现）

### 图片处理
- 高斯模糊 / 马赛克，整图或局部打码
- 缝隙柔和过渡：接缝处羽化融合，可调羽化宽度与间隙颜色

### 导出
- 预设尺寸：1080×1080、竖版 3:4、横版 4:3、自定义宽高
- 也可按原图质量导出（不损失清晰度）
- 格式 PNG / JPG（JPG 可调质量）
- 一键复制到剪贴板

## 非功能性
- 最终交付双击即用 exe（PyInstaller 单文件）
- 增量开发，一次一个阶段，稳定安全推进

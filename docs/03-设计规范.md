# 设计规范

## 配色（橙白）
| 用途 | 色值 |
| --- | --- |
| 主橙 | `#FF8C1A` |
| 主橙悬停 | `#FF9E40` |
| 主橙按下 | `#E67600` |
| 主背景白 | `#FFFFFF` |
| 柔和暖白 | `#FFF6EE` |
| 面板底色 | `#FFFDF9` |
| 边框 | `#F0E0D0` |
| 正文文字 | `#333333` |
| 次要文字 | `#8A7A6B` |

所有颜色统一定义在 `app/theme.py`，其他文件不得硬编码色值。

## 布局
- 顶部工具条：导入 / 模板 / 模式切换 / 导出·复制
- 左侧：缩略图库
- 中央：拼图画布
- 右侧：属性面板
- 分组条：可停靠到上/下/左/右任意一边

## 交互约定
- 拖拽导入、拖拽换位、拖框线改比例
- 主操作按钮用主橙填充，次要操作用描边样式

## 文案
- 一律中文，简洁直白，避免英文术语

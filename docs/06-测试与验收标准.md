# 测试与验收标准

| 阶段 | 验收标准 |
| --- | --- |
| 0 | `python main.py` 打开橙白配色空窗口，不报错 |
| 1 | 拖拽/粘贴/批量导入几十张，缩略图库正确显示，可增删 |
| 2 | 建 ≥9 组、每组 1~9 张、支持跨组拖动、分组条可停靠/缩放 |
| 3 | 套模板、格间换位、拖框线、格内缩放裁切、DIY/导入模板 |
| 4 | 自由摆放、重叠、置顶/置底 |
| 5 | 高斯模糊/马赛克/局部打码/缝隙虚化生效 |
| 6 | 导出 1080×1080 等尺寸、复制到剪贴板、原图质量导出 |
| 7 | `python build.py` 生成 exe，双击可用 |

每个阶段结束后，检查 `dev-log/` 当天日志已更新。
